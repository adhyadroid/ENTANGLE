ENTANGLE

A threat detection framework for teleportation-based quantum digital signatures. It catches forgery, spoofing and replay using physics and plain statistics, not a trained model.

Protocol
ALICE - prepares a Pauli-eigenstate signature token
BELL PAIR - shared with Bob and with Charlie
TELEPORTATION - Bell measurement, then classical bits sent
PAULI CORRECTION - applied at the receiver
BOB + CHARLIE - independent measurement, compared to the signature token
SPRT - sequential likelihood ratio test, run by each verifier
SECURITY DECISION - both verifiers have to agree
